# Progen Labs
Building the next generation of open-source software solutions.

# About Us
Born from its original internal codename "Project First Child," the name Progen derives from progeny—symbolizing a flagship creation built from the ground up with deep care and dedication.
Progen Labs is an independent, open-source lab dedicated to solving complex software and productivity problems through innovative, high-performance tools.

# What We Build
- Collab Tools & Engines: High-performance software designed to bridge workflows between cross-functional teams.
- Open-Source Primitives: Developer-friendly libraries and infrastructure for modern web applications.
